# 프로젝트 소개

### 분류 기준
- 팀 프로젝트: 혼자가 아닌 여러명이서 진행한 프로젝트
- 사이드 프로젝트: 일정 기간 이상 유지보수하거나 운영한 경험이 있는 프로젝트
- 토이 프로젝트: 단기간에 개발되었거나 중단되었지만 어느 정도 동작하는 프로젝트

## 팀 프로젝트
- [hellogsm-server](https://github.com/themoment-team/hellogsm-server) (2022. 04 ~ 2023. 09): 'Hello, GSM'이라는 광주소프트웨어마이스터고등학교 입학 지원 서비스의 백엔드
  - 기술 스택: SpringBoot, Java, Gradle, JPA

## 사이드 프로젝트
- [Inline Toggle Notes](https://github.com/YangSiJun528/inline-toggle-notes) (2025.07~): 노트 안의 다른 노트를 토글로 열 수 있게 해주는 옵시디언 플러그인 *(Obsidian, TypeScript)*
- [YangSiJun528.github.io](https://github.com/YangSiJun528/YangSiJun528.github.io) (2025.07~): 이 글이 보여질 수 있게 하는 정적 블로그 생성기 *(TypeScript)*

## 토이 프로젝트
- [docsify-c-runner-plugin](https://github.com/YangSiJun528/docsify-c-runner-plugin) (2025.05): Docsify 문서에서 C 코드를 실행할 수 있게 해주는 플러그인 *(Docsify, TypeScript)*
  - [데모 링크](https://sijun-yang.com/docsify-c-runner-plugin/#/)
- [c-runner-api-server](https://github.com/YangSiJun528/c-runner-api-server) (2025.05): C 코드를 실행할 수 있는 API 서버를 제공하는 컨테이너 *(Docker, Python)*
- [c-chip-8](https://github.com/YangSiJun528/c-chip-8) (2025.04): C언어로 작성된 CHIP-8 에뮬레이터 *(C)*
- [hakko](https://github.com/YangSiJun528/hakko) (2025.01): CHZZK와 SOOP에서 시청자가 적은 새로운 스트리머를 랜덤하게 보여주는 사이트 *(Spring Boot, HTMX)*
